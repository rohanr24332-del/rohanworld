# Unreal Engine 5 Open World Project

An Unreal Engine 5 open-world project focused on building immersive natural environments and gameplay systems. This repository serves as a foundation for experimenting with large landscapes, environmental design, and interactive mechanics.

## Overview

The current prototype features an expansive outdoor environment with mountains, water bodies, and detailed terrain created using Unreal Engine 5's rendering technologies.

## Current Features

- Open-world landscape
- Large terrain with natural environments
- Dynamic lighting and atmosphere
- Water system integration
- Third-person character controller
- Environment prototyping
- Unreal Engine 5 rendering pipeline
